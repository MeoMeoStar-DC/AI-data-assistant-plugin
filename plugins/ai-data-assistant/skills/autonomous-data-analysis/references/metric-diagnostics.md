# 指标变化与异常诊断

用于收入变化、指标异常和人群结构比较。复用入口 Skill 的合同、SQL 展示、来源与预算规则；不再发起一套取数流程。

## 验证需要解释的变化

从同一合同取得比较侧、指标公式、单位、人群和粒度。先计算两侧实际值、差值和有意义的变化率。前提不成立时，直接纠正前提并解释实际变化，不继续寻找不存在的下降原因。数据不完整时只描述有证据的范围。

## 选择值得继续的下钻

维护简短的调查记录：候选解释、验证所需事实、已有 evidence 引用、支持/反驳/尚未验证状态、下一步。它是会话内工作记录，不是持久化事务或服务端验证凭证。

优先选择可能改变结论、能量化影响且成本可控的维度。复用已有事实；兼容分组合并成一次查询，不逐实体重复预览执行。不为“发现更多”而扫描所有来源或组合所有维度。额外查询不能突破原请求期间、人群和预算。

- 可加总指标：用互斥且完整的分组解释总差值，同时保留正负贡献。核对分组差值之和与总差值，并显示无法解释的剩余项。新增、退出与两侧均存在的群体分开解释；缺行不自动补零。
- 比率：取得正式分子分母后重算，区分组内表现与人群结构变化。只拿到聚合比率时不做假精确分解。
- 人群：比较人数、占比和业务结果；跨日或跨 App 人数按正式身份键重算，分群交叠时不得相加当作全体。
- 异常：核对发生时点、持续时间、是否集中于某些群体及是否为不完整周期。考虑同星期、季节性和基数变化，不能凭单日峰谷宣称异常。

总差值为零或接近零时，以绝对贡献解释抵消，不输出不稳定的净变化贡献率。比较多个维度时明确它们是同一变化的不同切面，不把渠道与产品的贡献再次相加。

## 验证发现并停止探索

针对主要候选选择最能区分解释的检查，例如换用可比窗口、查看分子分母或核对关联覆盖。排除小样本与数据质量问题。多次切分得到的异常先标记为探索性候选；未经多重比较控制或独立窗口验证，不声明统计显著。没有可执行的统计工具或必要样本时，只报告描述性事实。

证据已能回应请求、后续查询不会实质改变结论或预算耗尽时收口。预算不足保留可信结果及具体未验证项，不原样重试相同失败计划。

结论分别标记量化贡献、相关现象与待验证解释；因果判断必须有匹配的实验或识别设计。推荐下一步应针对一个具体证据缺口，不把“建议进一步分析”当作发现。
